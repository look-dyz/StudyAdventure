# 开发指南（新手入门）

> 给三位队员看的"第一周怎么动手"指南。

## 1. 环境搭建（5/13 完成）

### 装 Qt 6

去 https://www.qt.io/download-qt-installer 下载 Qt Online Installer：

- **Windows**：双击 `.exe` 安装。在组件选择页勾选：
  - Qt 6.6 或更高版本（点开看子选项，勾选 MinGW 或 MSVC 编译器，二选一即可）
  - Developer and Designer Tools → Qt Creator（自动勾选）
  - Developer and Designer Tools → CMake（自动勾选）

- **macOS**：装好后会在应用程序中看到 Qt Creator
- **Linux**：可用包管理器，也可用 Installer

### 验证安装

1. 打开 Qt Creator
2. 文件 → 打开文件或项目 → 选择仓库根目录的 `CMakeLists.txt`
3. 配置项目 → 选择你装好的 Qt 6 Kit
4. 点击左下角绿色三角形 ▶ 运行

如果能看到主菜单窗口，说明环境 OK。

## 2. 第一次拉代码

```bash
# 把队长邀请你为 Collaborator 后
git clone https://github.com/<队长用户名>/StudyAdventure.git
cd StudyAdventure

# 拉取开发分支
git checkout develop
git pull

# 创建自己的 feature 分支
git checkout -b feature/<你的模块>-<功能名>
# 例如：feature/story-engine、feature/ui-mapscene、feature/game-minesweeper
```

## 4. 怎么调试

### 看运行时输出

代码里有大量 `qDebug() << "..."`。在 Qt Creator 中运行后，输出在 **应用程序输出** 面板。

### 打断点

Qt Creator 里点行号左侧空白即可加断点，然后点 🐞 调试按钮（不是普通运行）。

### 找崩溃位置

如果游戏直接闪退，去 Qt Creator 的 **问题** 面板看编译警告/错误，或在 Linux/Mac 命令行运行 `./StudyAdventure` 看 core dump 信息。

## 5. 怎么提交代码

```bash
# 1. 在自己的 feature 分支上修改文件
# 2. 看一下改了什么
git status
git diff

# 3. 暂存
git add src/story/StoryEngine.cpp
# 或者全部暂存
git add .

# 4. 提交（注意提交信息格式）
git commit -m "[story] 实现 jumpToNode 节点跳转逻辑"

# 5. 推到远程
git push origin feature/story-engine

# 6. 去 GitHub 网页上发起 Pull Request 到 develop 分支
# @ 队友 review
```

## 6. 常见问题

**Q：编译报错 `find_package(Qt6) failed`？**
A：CMake 找不到 Qt 6。在 Qt Creator 中确保选择了正确的 Qt 6 Kit；或者命令行用 `cmake -DCMAKE_PREFIX_PATH=/path/to/Qt6 ..`。

**Q：编译报错 `undefined reference to vtable for XXX`？**
A：你给一个有 Q_OBJECT 宏的类添加了新文件，但 CMake 没收录。检查 `CMakeLists.txt` 的 `PROJECT_SOURCES` 里有没有你的新文件，加上后**完全删除 build 目录**重新配置。

**Q：JSON 文件改了没生效？**
A：如果资源已经打包进 .qrc 了，要在 `.qrc` 中重新引用（自动重新编译）。开发期间建议直接用文件系统路径读取（如 `assets/scripts/week1.json`），改了立刻生效。

**Q：Git 冲突了怎么办？**
A：先别慌。冲突会标记在文件里：
```
<<<<<<< HEAD
你的版本
=======
他的版本
>>>>>>> branch
```
手动改成你想要的样子，然后 `git add` 那个文件，再 `git commit`。如果完全搞不定，**问群里**别硬扛。

**Q：Qt Creator 中文乱码？**
A：菜单 → 工具 → 选项 → 文本编辑器 → 行为 → 默认编码改为 UTF-8。
