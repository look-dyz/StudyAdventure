## 一、项目简介与核心玩法

玩家扮演北大信科大一女生，期末通宵学习后晕倒穿越至异世界，与拟人化学科（**程设、高数、线代、人工智能引论**）共度一学期。通过**剧情推进、自由探索、知识小游戏**提升角色好感度、管理压力值与黑化值，最终触发多种结局。游戏融合养成、模拟、解谜元素，玩法寓教于乐。


## 二、核心系统设计

| **系统模块** | **功能描述** |
| --- | --- |
| **剧情系统** | **第一周**线性剧情(认识四学科) → **中期**自由探索 → 触发好感度特殊剧情(获信物) → **期中考试**(小游戏) → 出游剧情(双人/多人) → **期末考试**(剧情过) → 多结局判定 |
| **数值系统** | **好感度**(每位学科独立，0-100)、**压力值**(0-100，>=100触发end5)、**线代黑化值**(满值触发end4)、**学习能力**(影响小游戏奖励)。各数值随玩家行为动态变化。 |
| **地图探索** | **教学楼**(上课/逃课，逃课降好感+黑化)、**图书馆**(自习+小游戏，好感↑/压力↑)、**未名湖**(同游触发哲学讨论)、**宿舍**(休息，压力↓)。每日按时段制行动。 |
| **小游戏** | **扫雷**(程设)、**21点**(程设)、**井字棋**(AI引论，含α-β剪枝AI对手)、**矩阵运算**(线代)、**AI迷宫逃生**(BFS/DFS路径展示)、**高数答题**(高数)。胜利↑好感，失败↑压力。 |


## 三、多结局设计

**End1 「3.92」**：默认结局，回归现实，期末取得优异成绩；   **End2 「Best Love」**：好感达标且选「留下」，留在异世界；   **End3 「再见」**：好感达标但选「离开」，回现实并收到学科短信；

**End4 「永远的线代」**：线代黑化值满，被囚禁于线代世界；   **End5 「陌生的天花板」**：压力值≥100，眼前一黑，于现实医院中醒来。


## 四、技术架构与类设计

**整体架构：**MVC分层 + Qt信号槽事件驱动。**Model**(Player/Subject/数值)与**View**(QMainWindow/QDialog/QGraphicsScene)解耦，由**Controller**(GameManager单例)统一调度；用QStackedWidget在主菜单/地图/对话/小游戏间切换。

| **核心类** | **OOP特性** | **职责与关键接口** |
| --- | --- | --- |
| **Subject**（基类） | **抽象类·纯虚函数·多态** | 纯虚接口 **virtual void interact()=0;  virtual MiniGame* createGame()=0;**  派生 **ProgDesign / Calculus / LinearAlgebra / AIIntro** 四子类各自override，运行时通过基类指针 Subject* 调用——展示运行时多态。 |
| **MiniGame**（基类） | **继承QWidget·虚函数** | 继承 QWidget，定义 **virtual void start();  signals: void finished(int score);** 6个小游戏均派生自此，通过信号槽统一回传分数给GameManager。 |
| **GameManager** | **单例模式 Singleton** | 全局唯一实例，构造函数私有，提供 **static GameManager**&** instance();** 持有Player与四个Subject对象，统一管理游戏状态切换、数值变更广播、存档触发。 |
| **Player** | **封装·RAII** | 私有数据成员(stress / items / affinity映射) + 公有getter/setter；用 **std::unique_ptr** 管理背包物品避免裸指针。所有数值修改通过setter发出 valueChanged() 信号驱动UI刷新。 |
| **StoryEngine** | **数据驱动·状态机** | 用 **QJsonDocument** 解析外置JSON剧本，节点含台词/选项/条件/数值变更指令；基于有限状态机 (currentNode → choices → nextNode) 推进，剧情与代码彻底分离，便于剧本同学独立编写。 |
| **MapScene** | **继承QGraphicsScene** | 重写 **mousePressEvent()** 实现热区点击；含Location子对象列表，玩家点击触发对应事件并推进游戏内时间。 |
| **SaveManager** · **EndingJudge** | **工具类·策略** | 前者负责JSON序列化存读档(支持多存档槽)；后者按优先级链 **压力满 **>** 黑化满 **>** 好感+留下 **>** 好感+离开 **>** 默认** 判定End1~5。 |

**技术亮点：**① **智能指针**(unique_ptr/shared_ptr)管理动态对象，杜绝内存泄漏；② **信号-槽机制**实现模块解耦，数值变更自动驱动UI刷新；③ **JSON数据驱动**使剧情/数值配置可热修改；④ **Qt资源系统(.qrc)**管理立绘/音乐；⑤ **CMake跨平台构建** + Git/GitHub协作开发。
