# 角色设定 · 美术参考（成员 A → 成员 B）

> 这份文档是给画立绘的成员 B 看的。每个角色给出：人设要点、外观要点、颜色 palette、装饰细节、表情库、台词样例（帮你抓神态）、**避免出现的画法**。
>
> 风格基准：日式校园 galge 立绘，半身/全身一图多差分（默认表情 + 2-3 个情绪差分），透明背景 PNG，建议 1080×1920 单人立绘。

---

## 🌐 总体定位

四人都是**拟人化的学科**，所以视觉上要兼顾：
1. **大学生女性外形**——年龄看起来 19-22，不要画成中学生或太成熟的老师
2. **学科特征以隐喻方式融入**，不要画成"穿着印满数学公式的衣服"这种字面化设计
3. **辨识度**：四人并列时，剪影、配色、姿态各不相同，能一眼分清

校园背景设定在异世界，所以服装可以略带超现实/奇幻元素，但**保持日常感**——不要画成 cosplay 服。

## 1️⃣ 程设 ProgDesign · 程序设计

### 一句话
**严苛但温柔的助教学姐型**。理性、克制、不说废话，对学生有近乎工匠的耐心。

### 外观要点

| 项 | 设定 |
|---|---|
| 身高 / 身型 | 168cm，挺拔、姿态板正 |
| 年龄感 | 22 左右，有"研究生 / TA"气质 |
| 发型 | 黑色或深棕**短发**，齐耳到下颌，发尾整齐，无碎发 |
| 眼睛 | 灰黑色，**目光锐利、不躲闪**，瞳孔常带"在审视代码"的感觉 |
| 服装 | **白衬衫扎进高腰深灰长裤**，外搭一件浅灰针织开衫或西装马甲；袖口扣紧 |
| 鞋 | 平底乐福鞋，黑色 |
| 配饰 | 一支**钢笔**插在胸前口袋——这是 week4 的信物伏笔，**画立绘时要画出来** |

### 配色 palette

```
主色：#1A1A2E（近黑深蓝）
辅色：#E8E8E8（米白）
点缀：#6C7A89（钢灰）
```
冷色调，几乎无暖色，传达"理性"。

### 表情库

| 差分 | 神态 | 用在哪 |
|---|---|---|
| **默认** | 平视，嘴唇微抿，眉头不皱不展 | week1~2 常规对话 |
| **微微鼓励** | 嘴角难以察觉地上扬一点，眼睛稍稍眯起 | 玩家答对题、week4 送钢笔时 |
| **失望/严厉** | 眉头微皱，目光下移，嘴抿紧 | 玩家翘课、玩手机时 |
| **罕见破防** | 眼眶发红但绷住，嘴唇抿成一条线 | week5 告别时 "讲题原来也可以是温柔的事" |

### 台词样例（抓气场用）

> "推迟一次，就会有第二次、第三次——我见过太多人是这样把自己推下悬崖的。"
> "工具的价值，是看它在谁手上。你不是替代我——你是接过我没走完的那一段。"

### ❌ 不要

- 不要画成戴眼镜的高冷御姐——**她不戴眼镜**，目光本身就够锐
- 不要长发——长发的"温柔"和她"剪断废话"的气质冲突
- 不要短裙、不要任何贴身的设计——她的服装应该是"职业感"而非"性感"

## 2️⃣ 高数 Calculus · 高等数学

### 一句话
**神秘的哲学系学姐型**。话不多，每一句都带哲思，温和但不可亲近。

### 外观要点

| 项 | 设定 |
|---|---|
| 身高 / 身型 | 165cm，纤细、动作慢半拍 |
| 年龄感 | 21-22，**有"湖边读旧书"的气质** |
| 发型 | **柔顺的中长卷发**（自然卷不是烫的），栗色或深棕，常被风吹乱也无所谓 |
| 眼睛 | 深褐色，**总像在看很远的地方**，瞳孔焦距常飘忽 |
| 服装 | **米白色或浅杏色的及膝连衣裙** + 针织开衫；衣领是简约的圆领或方领 |
| 鞋 | 白色帆布鞋 |
| 配饰 | 手里常**捧着一本旧书**——书脊上若隐若现写着《变与不变》，这是 week4 的信物 |

### 配色 palette

```
主色：#E8DCC4（杏米）
辅色：#9CAF88（雾绿）
点缀：#3A3A3A（黑墨）—— 书脊、瞳孔
```
偏暖但低饱和，**像旧书页和秋天的湖**。

### 表情库

| 差分 | 神态 | 用在哪 |
|---|---|---|
| **默认** | 微微低头、眼帘半垂，嘴唇放松 | week1 第一节课、所有讲题场景 |
| **若有所思** | 抬头望远处，眼神涣散 | "这些星光是几百年前发出的" |
| **罕见微笑** | 嘴角轻微弯起、眼神柔和 | week2 笑出来"截止日期是大学生的渐近线" |
| **沉思忧郁** | 长睫毛压下，全脸阴影 | route_calculus 哲学问题"死亡是不连续点还是极限" |

### 台词样例

> "趋近，但永不到达。你不觉得这很像爱情吗？或者——人生本身。"
> "积分的本质——是把无穷个微小的瞬间，重新连成一段人生。"

### ❌ 不要

- 不要画成卷发但很活泼的少女——**她要慢、要静、要遥远**
- 不要明亮的配色（粉、红、亮黄）——这会破坏她的"旧时光感"
- 不要书法/数学公式贴在裙子上——隐喻应该藏在书里，不是显在身上

## 3️⃣ 线代 LinearAlgebra · 线性代数 ⚠️ 重点

### 一句话
**克制的、研究员气质的、看人时像在看一个变量的存在**。**不是 yandere 恋人型**。她对玩家没有情感，只有秩序与归档欲。

### 外观要点

| 项 | 设定 |
|---|---|
| 身高 / 身型 | 160cm，瘦削、动作精确得像几何作图 |
| 年龄感 | 21，**有"档案管理员 / 图书馆员"的气质** |
| 发型 | **乌黑长直发**，垂到锁骨下，**几乎不动**——靠这种"不动"产生不安感 |
| 眼睛 | 深灰偏冷的眼瞳；**瞳孔特别小**，**虹膜上隐隐有同心圆刻度**（细节，给她"测量仪"的感觉）|
| 服装 | **深蓝色或墨黑色高领毛衣 + 直筒长裙到脚踝**；冬天再加一件长款风衣；**整个人遮得非常严** |
| 鞋 | 黑色低跟皮鞋 |
| 配饰 | **左手腕戴一只老式机械腕表**（她爱掐时间）；口袋里随时有一本**小本子和钢笔**——记录玩家行为；week4 后**玩家脖子上有她送的银项链**（链坠是首字母字母片）|

### 配色 palette

```
主色：#1B1E3F（深蓝近黑）
辅色：#2A2A2A（墨黑）
点缀：#A0A0B5（冷银 —— 腕表、项链、虹膜的"刻度"反光）
```
**几乎没有任何暖色**。她整个人像处于一个低色温的房间里。

### 表情库

⚠️ **特别重要**：她**几乎不变表情**。差分之间的差异要靠**眼神微调和嘴部状态**，不要靠夸张的情绪。

| 差分 | 神态 | 用在哪 |
|---|---|---|
| **默认** | 直视镜头/玩家，**眼睛不眨**，嘴唇平直，全身静止 | 90% 场景 |
| **微微关注** | 眼睛**完全锁定一点**（玩家），头微倾一度 | "你今天和程设说话的时间比和我多 23 分钟" |
| **机械微笑** | 嘴角向上 5°，**但眼睛完全不变** —— 笑得像 AI 模仿人类笑容 | week3 黑化路线 "微笑——重要的事情，当然要记下来" |
| **彻底冰冷** | 嘴唇没有任何弧度，眼神聚焦但完全无光 | End4 "你不会从我的坐标系里出去" |

### 标志性动作（让美术加入立绘语言）

- **数着腕表**——左手腕翻过来看时间
- **小本子翻开一页放在桌子中央**——这是她"出示档案"的动作
- **手指轻轻敲桌面**，节奏整齐（一秒一下，像节拍器）
- **凝视一个固定点不眨眼**——比看你眼睛更可怕

### 台词样例

> "（她从口袋里掏出一个小本子）这是你这两周吃过的所有东西。周一面、周二米饭、周四饺子——你比你以为的有规律。"
> "（她把链子的扣环用钳子掰紧）这个扣——是我特地改的，自己拿不下来。这样——你就不会从我的坐标系里失踪。"

### ❌ 不要 ⚠️ 重点

- **不要把她画成"病娇"或"哥特萝莉"类型**——她不是失控的爱人，是**克制的观察者**
- **不要让她哭、不要让她脸红、不要让她嘴角咧开大笑**——任何明显情绪都破坏人设
- **不要画"想拥抱玩家"或"伸手抓玩家"的姿势**——她不会主动触碰人，**她让物代劳**（项链、本子、腕表）
- **不要露肤**——她全身遮得严严实实，这本身就是她"封闭"性格的视觉表达
- **黑化结局立绘里不要画疯狂表情**——End4 那种结局她应该比平时更**安静**，因为目标已经达成

## 4️⃣ AI 引论 AIIntro · 人工智能引论

### 一句话
**酷感的极客学姐型**。话不多但句句带料，永远像在观察 + 调侃，但不毒舌。

### 外观要点

| 项 | 设定 |
|---|---|
| 身高 / 身型 | 167cm，姿态放松带点慵懒 |
| 年龄感 | 22，**有"创业团队里那个会写代码的酷女孩"气质** |
| 发型 | **银灰色或浅蓝挑染的中短发**（自然色染了一缕异色），发梢有点凌乱故意感 |
| 眼睛 | 浅琥珀色或冰蓝色，**目光带笑意**但不外露 |
| 服装 | **oversized 灰色卫衣 + 工装裤 + 帆布鞋**；卫衣胸前印一个极简的几何 logo（不要印任何 AI 公司真实 logo）|
| 鞋 | 高帮帆布鞋，**鞋带松松绑着** |
| 配饰 | **一只耳朵戴着小小的金属耳钉**——这是 week4 的信物伏笔；脖子上挂一台**老式相机**或**降噪耳机** |

### 配色 palette

```
主色：#4A5568（暖灰）
辅色：#7B9EA8（雾蓝）
点缀：#E0E0E0（冷白 —— 耳钉、相机金属反光）
```
不冷不暖，像电子设备的温度。

### 表情库

| 差分 | 神态 | 用在哪 |
|---|---|---|
| **默认** | 半眯眼，嘴角带一点点上扬，**好像随时要吐槽** | 大部分场景 |
| **真心被逗笑** | 眼睛弯成月牙，嘴角自然上扬，不夸张 | 玩家说"那为什么我也很在意你"等 |
| **认真观察** | 目光收敛，单边眉毛微抬 | "你这个学期最大的进步，不是知识，是容忍不确定的能力" |
| **罕见温柔** | 眼神柔和，嘴唇微张但没说话 | week5 天台告别 |

### 标志性动作

- **耸肩**——经常用这个动作代替说话
- **架起相机/拿起手机拍照**——是她常用的"记录方式"，对比线代的小本子
- **戴着耳机时单手把一只耳塞摘下递给玩家**——温暖的招呼方式

### 台词样例

> "学习这件事，本质上是反向传播——你今天卡在哪一题上，比你做对了几题更重要。"
> "我说——「在分布之外的某个点上」。意思是：不论你去哪里，我都会带着这一个学期的权重，往你存在的方向更新。"

### ❌ 不要

- 不要画成偶像歌手风（亮片、夸张配饰、彩色衣服）——她是**穿得舒服比穿得好看更重要**的人
- 不要让她皱眉/严肃——AI 的招牌是**带笑意但不外露**
- 不要把她画成"程序员宅"——她有美感，只是慵懒

## 🌈 四人并排时的视觉对照

| | 程设 | 高数 | 线代 | AI |
|---|---|---|---|---|
| 主色调 | 黑白灰 | 杏米雾绿 | 深蓝墨黑 | 暖灰雾蓝 |
| 服装风格 | 职业整洁 | 复古文艺 | 古旧严密 | 现代慵懒 |
| 发型 | 短发利落 | 中长卷 | 长直发 | 中短带挑染 |
| 标志物 | 钢笔 | 旧书 | 腕表/小本/项链 | 耳钉/相机 |
| 姿态 | 挺拔 | 慵懒 | 静止 | 放松 |
| 体温感 | 冷 | 温 | **极冷** | 中性 |

并排立绘建议**程设最左、高数次之、线代倒数第二、AI 最右**——这样从严肃到放松、从冷到中性的渐变最舒服。

## 📦 交付建议

每个角色出 **3 个差分**：

1. **default.png** —— 默认表情
2. **happy.png** —— 鼓励 / 温柔（线代换成"机械微笑"）
3. **stressed.png** —— 失望 / 锐利 / 凝视

文件命名建议：

```
assets/images/characters/
├── progdesign_default.png
├── progdesign_happy.png
├── progdesign_stressed.png
├── calculus_default.png
├── calculus_happy.png
├── calculus_stressed.png
├── linearalgebra_default.png
├── linearalgebra_smile.png       ← 注意她的"happy"叫 smile（机械笑）
├── linearalgebra_stare.png       ← 凝视版
├── aiintro_default.png
├── aiintro_happy.png
└── aiintro_observing.png
```

尺寸 1080×1920 PNG 透明背景，先出占位草稿/线稿给 A 看一眼气质对不对，再上色。
