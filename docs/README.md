## 🛠 VSCode 预览技巧

1. **打开 .md 文件**
2. **快捷键 Ctrl+Shift+V**（Mac: Cmd+Shift+V）→ 新标签页预览
3. 或者 **Ctrl+K V** → 侧边栏预览（一边编辑一边看效果）

推荐扩展（可选）：
- **Markdown All in One** — 目录大纲、自动列表续号
- **Markdown Preview Enhanced** — 更漂亮的渲染、支持思维导图等

## ✏️ 文档维护说明

| 文件类型 | 怎么改 |
|---|---|
| `.docx` 文档 | 直接改 docx 源文件 |
| 从 docx 转换的 `.md` | **不要直接改**（下次同步会被覆盖） |
| 原生 `.md`（接口约定/开发指南/协作流程/JSON剧本格式/疑难解答） | 直接改 md |

如果改了 docx 源，可以让队长重新生成 md 版本（用我们的转换脚本）。
