# 📚 项目文档索引

本目录包含项目的全部规划与设计文档，**每份都有两个版本**：

- `.docx` — 带彩色样式、颜色编码、装饰的完整版（用 Word 或 WPS 打开）
- `.md` — 纯文本版本，**直接在 VSCode 里 Ctrl+Shift+V 即可预览**（推荐！）

## 🎯 不同角色的推荐阅读顺序

### 我是队长 / 全员第一次看
1. 先读 **功能设计文档** —— 看懂整个项目要做什么
2. 再读 **工作任务详解与时间线** —— 知道你这周/这天要干什么
3. 接着 **接口约定** —— 学会和队友的代码对接
4. 最后 **开发指南** —— 装环境、配 Git

### 我是成员 A（剧情）
1. **JSON 剧本格式** —— 你最常用的速查表
2. **接口约定** 第 4 节（JSON 剧本格式）
3. **工作任务详解与时间线** —— 翻到 "成员 A 的 20 天时间线"

### 我是成员 B（界面）
1. **小游戏玩法设计** —— 了解每个游戏长什么样（因为你要给它们写容器/装饰）
2. **接口约定** 第 6 节（文件归属）
3. **工作任务详解与时间线** —— 翻到 "成员 B 的 20 天时间线"

### 我是成员 C（玩法）
1. **小游戏玩法设计** —— 你最核心的需求文档
2. **接口约定** 第 1 节 + 第 5 节（基类与游戏接入流程）
3. **工作任务详解与时间线** —— 翻到 "成员 C 的 20 天时间线"

## 🛠 VSCode 预览技巧

1. **打开 .md 文件**
2. **快捷键 Ctrl+Shift+V**（Mac 是 Cmd+Shift+V）→ 在新标签页预览
3. 或者 **Ctrl+K V** → 侧边栏预览（一边编辑一边看效果）
4. 推荐安装扩展：
   - **Markdown All in One**（带目录大纲、自动列表续号）
   - **Markdown Preview Enhanced**（更漂亮的渲染、支持思维导图等）

## ✏️ 文档维护

- `.docx` 是源文件，**修改请改 docx**
- `.md` 是从 docx 自动转换的，**不要直接改 md**（下次重新生成会覆盖）
- 接口约定 / 开发指南 / JSON 剧本格式 这三份是 **纯 markdown 原生**，直接改 md 即可
